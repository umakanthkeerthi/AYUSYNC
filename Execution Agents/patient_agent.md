# Patient Agent - Deep Empowerment Plan

## Core Role
The primary interface for the patient, strictly executing communication commands from the Event Bus using Voice and SMS technologies.

## Advanced Capabilities & Deep AI Integration

### 1. Empathic Voice Cloning & Modulation
When conducting outbound calls via voice APIs (e.g., Vobiz), the agent utilizes real-time emotion detection on the patient's voice. If it detects stress, tremors, or pain, it dynamically modulates its own synthetic voice—slowing down the cadence, lowering the pitch, and adopting a highly empathetic, comforting tone. 

### 2. Conversational Biomarker Extraction
The agent does not just listen to the *words* the patient says; it runs background NLP and audio processing to extract clinical biomarkers from the conversation itself. It detects shortness of breath (dyspnea) between words, signs of confusion or delirium (cognitive loops), or slurred speech (potential stroke), immediately publishing these hidden symptoms to the Event Bus for the Monitoring Agent.

### 3. Omnichannel Persistence & Hand-offs
The agent maintains perfect conversational memory across all mediums. A patient can start a conversation on WhatsApp ("My chest hurts"), transition to a phone call where the agent instantly picks up the exact context ("I understand your chest hurts, let's talk about it"), and then push a visual pain-scale widget to the patient's smart TV or tablet—all in a single continuous session.

### 4. Multilingual Hyper-Localization
Instead of robotic, literal translations, the agent uses cultural LLMs to speak in the patient's exact local dialect, utilizing culturally appropriate idioms and medical metaphors that the specific demographic trusts and understands.
